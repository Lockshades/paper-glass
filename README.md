# paper-glass

ExamPilot — AI-powered CBT exam preparation for Nigerian students (JAMB, WAEC, NECO).

## Overview

Full-stack monorepo:
- `artifacts/exampilot-mvp` — Student-facing CBT exam app (React + Vite)
- `artifacts/api-server` — Express API with AI tutor (gpt-4o-mini, SSE streaming) and operator admin routes
- `artifacts/admin-dashboard` — Operator dashboard with AI cost tracking, GitHub Issues, content moderation

## Stack
React · TypeScript · Vite · Express · OpenAI · Recharts · TailwindCSS · pnpm workspaces
