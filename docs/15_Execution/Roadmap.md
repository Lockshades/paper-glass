# Execution Roadmap

**Version:** 1.0  
**Status:** Directional baseline  
**Last updated:** 2026-07-27

This roadmap uses Now / Next / Later. Dates should be added only when capacity, evidence, and dependencies are known.

## Strategic goal

Validate that a student-first practice and feedback loop creates measurable learning value and repeat use.

## Now — prove the learning loop

1. Confirm first examination, subject, syllabus, and scoring rules.
2. Establish a small approved question bank.
3. Build student onboarding and practice-session creation.
4. Build timed CBT flow with save, resume, and submit.
5. Build deterministic scoring and result review.
6. Add verified explanations and bounded AI adaptation.
7. Add topic diagnostics and a basic next-action recommendation.
8. Add content reporting and operator review.
9. Instrument activation, completion, usefulness, and repeat practice.

## Next — improve learning and trust

1. Expand subject coverage.
2. Add stronger content review and consensus workflows.
3. Improve recommendation quality using observed learning signals.
4. Add account, subscription, or entitlement flows after value evidence.
5. Add tutor-centre pilot workflows.
6. Build AI evaluation and cost dashboards.
7. Formalize privacy, support, and incident playbooks.

## Later — platform expansion

1. contributor authoring and reviewer reputation;
2. contributor compensation and dispute handling;
3. institution administration and cohort analytics;
4. broader examination bodies;
5. richer question types;
6. adaptive testing when item calibration is sufficient;
7. marketplace and partner ecosystem;
8. mobile clients sharing the same learning platform.

## Prioritization rule

When two initiatives compete, prefer the one that most improves:

1. learning outcome;
2. academic trust;
3. repeatable evidence;
4. sustainable economics;

in that order, unless a safety, legal, or security issue requires immediate action.

## Milestone exit criteria

The first milestone is not complete because the interface exists. It is complete when a small cohort can use the product repeatedly, recover sessions, trust the content, understand feedback, and produce evidence that informs the next decision.
