## Initial experiments

### EXP-001 — First-value learning loop

**Status:** Proposed  
**Question:** Does a student who receives a result plus a focused next action return to practice more often than a student who receives only a score?

**Measure:** first-session completion, explanation engagement, next-action engagement, and return practice within seven days.

**Guardrail:** do not optimize return rate by making recommendations noisy or manipulative.

### EXP-002 — Trust of AI-assisted explanations

**Status:** Proposed  
**Question:** Does clearly labeling AI-assisted explanations while showing verified provenance increase or decrease student usefulness ratings and report rates?

**Measure:** usefulness rating, content reports, follow-up questions, and qualitative feedback.

### EXP-003 — Practice format and conversion

**Status:** Proposed  
**Question:** Is realistic CBT simulation or targeted topic practice the stronger first-value experience for the initial student segment?

**Measure:** activation, session completion, repeat practice, and willingness to pay when a payment test is appropriate.
